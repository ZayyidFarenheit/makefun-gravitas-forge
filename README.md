A tactical orbital gravity-slingshot defense game for [make.fun's "Make the best game" bounty](https://make.fun/bounty/best-game-01) — $1,000 in USDC.

Defend the living Forge-Star at the heart of a miniature solar system. Build orbiting Railgun Turrets, Gravity Repulsors, Dyson Collectors and Plasma Flak; bend every projectile around black-hole buoys and moons with real N-body gravity to strike the armored flanks of incoming dreadnoughts; harvest comet trails for Solar Plasma; spend Starlight Ore on an 8-node tech tree with two superweapons. Seven waves, a boss dreadnought — THE VOID MAW — and a win screen only if the Forge endures.

**Play:** mouse to aim, click to fire (watch the dotted gravity arc), keys 1–4 build structures, Q boosts decaying orbits, X fires the Nova Burst, P pauses, M mutes. Survive all 7 waves and destroy the Void Maw to win. If the Forge-Star's Core Integrity hits zero, the Forge falls.
